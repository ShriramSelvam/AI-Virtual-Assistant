# 🤖 AI-Powered Virtual Assistant

An AI-powered virtual assistant built using **Python and Natural Language Processing (NLP)** to help users perform everyday tasks such as setting reminders, managing schedules, and answering queries through text-based interaction.

This project demonstrates how conversational AI systems work internally, including intent detection, time parsing, reminder management, and continuous interaction handling.

---

## 📌 Features

- 🗣️ Natural Language Interaction  
- ⏰ Set reminders using human-readable phrases  
- 📋 View stored reminders  
- 🧠 Context-aware follow-up handling  
- 🧩 Modular and scalable architecture  
- 💻 Lightweight CLI-based interaction  

---

## 🛠️ Technologies Used

- Python 3  
- Natural Language Processing (NLP)  
- Datetime & Regex-based Time Parsing  
- JSON-based Local Storage
